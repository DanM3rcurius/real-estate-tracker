## muscle memory
### restart local server (in v-env w/o docker)
´´´bash
python scripts/backup_db.py     # → backups/hofradar-<timestamp>.db
hofradar migrate --check        # exits 1 while pending
hofradar init-db                # migrates + registers sources
hofradar serve                  # Ctrl-C to stop
´´´

### start service as docker
´´´ 
docker compose up -d --build
docker compose logs -f hofradar 
´´´ 

### restart VPS

#### quick restart
ssh hofradar@<box>
hofradar-update

#### full restart
´´´bash
cd /opt/hofradar/app
sudo hofradar-backup
git pull --ff-only
sudo systemctl restart hofradar
docker compose -f docker-compose.yml -f deploy/hetzner/docker-compose.prod.yml logs -f hofradar
´´´
